# AI-eval work market — analysis

Independent analysis of the market and ecosystem around **paid AI-evaluation and
model-testing work** — the platforms that pay for it, the tooling where the
methodology actually happens, and the structural gaps a practitioner runs into,
especially from the EU.

This is not a job board and not affiliate content. It carries no referral links.
Where a figure comes from affiliate-driven SEO material (most public "pay band"
data does), it is labelled as such and separated from platform claims and from
primary sources.

## Method (short version)

Each analysis follows the same protocol:

1. **Freshness window** stated up front; sources outside it are flagged.
2. **PROMISED vs OBSERVED** kept separate — a platform's advertised rate is never
   merged with contributor-reported effective rate.
3. **Confidence level on every claim**: High = primary source or ≥3 independent;
   Medium = several affiliate reviews in agreement; Low = single source or forum
   sentiment.
4. **Named bias**: forums over-represent complaints; review blogs are affiliate
   SEO; both are used, both are labelled.
5. **Query log** included so the search can be reproduced or challenged.

Full method section is in each document.
